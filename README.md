# ONE PIECE DRAWING · PASO A PASO

Repositorio nuevo y limpio para cargar los dibujos propios que se envíen después.

La portada ya tiene diez filas numeradas: Dibujo 1 a Dibujo 10. Cada una incluye pasos seleccionables y una pantalla de lienzo grande. Los dibujos definitivos se incorporarán únicamente a partir del material que se entregue.
